# Future Features Backlog

This prioritized backlog is a source for future GitHub issues.

## Highest priority

- Quiz-data validation with friendly errors for malformed, missing, invalid, or questionless quiz data.
- Unanswered-submission confirmation.
- Accessibility refinement: move focus after navigation and submission, and announce quiz progress to screen readers.
- GitHub Pages deployment workflow.

## Useful next

- Optional answer explanations in results.
- Quiz metadata for podcast or video title, episode, source link, topic, and estimated time.
- Quiz directory or parent-site integration after the framework is selected.
- Copy quiz link.
- Local content-validation command.

## Later/optional

- Images or diagrams.
- Explanations with external references or timestamps.
- Privacy-reviewed analytics.
- Authoring workflow documentation, schema, or a simple generator, but no CMS.

## Out of scope

- Authentication or saved progress.
- Formal grading or accreditation.
- Server or database dependencies.
- Full browser authoring tool.
